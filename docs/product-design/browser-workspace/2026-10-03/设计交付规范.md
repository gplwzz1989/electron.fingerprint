# 商业指纹浏览器设计交付规范

版本：2026-10-03。与 `高保真原型.html`、`prototype.css`、`prototype.js` 一起评审。设计不等于真实功能实现，原型数据在刷新后恢复。

## 1. 视觉方向

暂定名称“栖界”，正式品牌另行确认。冷白画布、深石墨导航、钴蓝主操作，围绕环境表格形成稳定工作空间。业务文案用中文，不在主流程暴露 Electron、Session、Schema 等实现术语；确有诊断价值时放在设置或详情。

原型字体使用系统字体栈；Windows 优先系统界面字体和微软雅黑，macOS 使用系统字体和苹方，无网络字体依赖。图标统一为 24×24 描边图标，线宽 1.7，控件中一般显示为 16—20px。图标不得单独表达错误或重要状态。

| 令牌 | 值 | 用途 |
| --- | --- | --- |
| 主色 | `#315BEA` | 主按钮、选中导航、关键链接 |
| 主色浅背景 | `#EDF2FF` | 次级强调、选中状态 |
| 正文 | `#192536` | 标题和正文 |
| 次级正文 | `#637083` | 说明和非关键辅助信息 |
| 画布 | `#F5F7FA` | 工作区 |
| 导航 | `#171E2B` | 持久侧栏 |
| 边框 | `#E5EAF0` | 表格和卡片分隔 |
| 成功 | `#16734D` | 连接成功、运行状态 |
| 提醒 | `#996014` | 代理异常、同步待处理 |
| 错误 | `#B94343` | 失败说明和高风险操作 |
| 卡片圆角 | 12px | 信息容器 |
| 控件圆角 | 7px | 按钮、输入、选择框 |
| 基础间距 | 4px | 8/12/16/20/24/32 级别 |

主要正文/按钮文本目标达到 WCAG AA；小字号次级元数据在实际开发需复查对比度，不因设计图好看降低可读性。交付前进行代表性颜色对比度检查，结果记录在验收报告。正文不通过压缩字号解决列宽不足，优先减少默认列、折叠或滚动。

## 2. 页面与画布

基准画布：1440×1000；主侧栏宽 224px，顶部 68px，主内容边距 32px。1024—1920 桌面宽度适配；宽度不足 1000 时导航折叠为图标，表格在自身容器滚动。

小于 760px 时指标为两列、页面正文单列、创建摘要移到表单下方、套餐单列；原型支持 320px 降级预览。这不是承诺手机版运行指纹浏览器。官网账户/计费控制台需另做移动端规格。

标题 27px/700，页面说明 12px，正文 14px 为生产组件标准；原型部分密集表格和说明使用 10—12px 展示信息层级，开发需按实际显示器可读性调至至少 12px 辅助文字、14px 主要表格文字。表格默认行高 56—60px，紧凑模式 44px。

## 3. 页面清单与评审路径

| 原型路由 | 页面 | 主要评审点 |
| --- | --- | --- |
| `#overview` | 工作台 | 最近环境、真实可处理事项、首次引导；减少装饰指标 |
| `#environments` | 环境管理 | 名称/编号/分组、地区与代理、负责人、同步、运行、操作 |
| `#create` | 创建向导 | 三步分层、默认本地保存、代理先检查、指纹摘要 |
| `#detail` | 环境详情 | 保留列表上下文，说明快照/保存方式/同步/权限 |
| `#diagnostic` | 启动失败诊断 | 原数据保留、代理失败阻止启动、具体处理路径 |
| `#proxies` | 代理资源 | 认证隐藏、检测时间、绑定数、导入前预览 |
| `#members` | 成员 | 角色和对象范围分开；邀请/停用/敏感导出 |
| `#audit` | 操作记录 | 操作、设备、结果、时间；脱敏导出 |
| `#billing` | 订阅与用量 | 价格为占位、单位透明、空间/席位/环境清晰 |
| `#settings` | 本机设置 | 实际内核能力、数据迁移、更新、诊断、三平台状态 |
| `#browser` | 环境浏览器 | 一个环境多个网页标签，下载/权限按环境归属 |
| `#empty` | 首次创建空态 | 明确下一步，不显示参数清单 |
| `#onboarding` | 工作空间引导 | 本地优先、保存方式、团队创建 |

原型默认打开工作台。进入环境列表，试着搜索、按分组/运行状态筛选、勾选批量开关；点击环境名称查看详情，点击“诊断”看失败处理。新建向导先检查代理再创建，创建后回列表或进入模拟浏览器。团队页支持增加演示邀请，不发送邮件。账单、导入、迁移和导出部分只演示预览与需求边界，没有连接真实服务。

## 4. 组件与状态约定

| 组件 | 基本规格 | 必须完成的状态 |
| --- | --- | --- |
| 按钮 | 主/次/轻量/危险；36/40px 高；图标 16px | 默认、悬停、焦点、禁用、处理中；禁用需可理解原因 |
| 输入与选择 | 40px 高，标签在上；输入错误附文字 | 空、输入、焦点、校验失败、异步检查、只读 |
| 表格 | 表头固定语义、明确单位、行操作区 | 加载骨架、空、筛选无结果、失败、已选、无权限 |
| 状态标签 | 颜色+文案+小图标/圆点，区分运行/同步/代理 | 不将已同步当作运行状态，不将可用代理当作已启动 |
| 抽屉 | 470px 宽，固定头尾，中间滚动 | 打开、加载、失败、无权限、版本冲突 |
| 对话框 | 500px，标题/主体/底部；确认操作要具体 | 焦点进入、Tab 循环、Escape 返回、关闭后回原入口 |
| 即时反馈 | 浮层 4 秒左右，中文可理解结果 | 成功、失败、部分成功；关键失败同时保留在页面 |
| 文件导入 | 选择→校验→预览→确认→逐项结果 | 错误行、重复、取消、中断、重试，不静默覆盖 |

运行状态不使用单个“健康度”或“安全分数”掩盖多个维度。诊断是“哪项检查失败、保留了什么、下一步如何做”，不是原始堆栈。高级字段用说明与实际能力标记区分“已验证/待验证/不支持/未启用”。

## 5. 关键交互规则

### 环境列表与详情

默认表格主操作为“打开”；运行中显示“进入”；代理异常显示“诊断”。从详情关闭环境，需要等待 Session 数据刷新成功后更新状态。批量打开遇到异常时逐项反馈，不假定全成功。

筛选跨页选择在正式版需明确范围：仅当前页、全部搜索结果或指定 ID；原型只有一个演示页。切换筛选时已选 ID 保留，批量条显示总数。生产实现必须提供选择范围说明和清空入口。

抽屉首版包含概览、指纹快照、活动三个内容页；本稿绘制概览并展示另外两个分栏位置，交互尚未接内容。生产实现需接入真实数据或隐藏尚未支持的分栏，不能呈现可点击但无反应的控件。

### 创建与修改

第 1 步基本信息/保存方式，第 2 步代理/语言/时区，第 3 步模板摘要/高级参数。必填校验失败留在当前步骤；代理尚未检查则不能继续。更换代理后使旧检查失效，需重新检查；正式版检查有时效和唯一结果 ID。

创建时生成稳定环境种子并保存快照。后续“编辑名称/标签”等业务元数据不会修改指纹。修改指纹需说明影响、关闭窗口、创建新修订或克隆环境；绝不对锁定 Session 热更新。

用户选择云同步时，正式创建前需告知上传内容、获授权成员与同系统/跨系统恢复限制。原型将这些设计限制写在摘要，具体可发布文案须与最终能力一致。

### 删除与恢复

优先回收站。永久删除时显示名称、ID、影响的数据、保留期和仍在使用的设备；处于运行或租约占用时禁止删除。路径边界检查在可信主进程执行。Windows 文件仍被占用时展示“等待清理”，不伪装为已物理删除。

### 协作与订阅

邀请邮箱需校验，角色与分组必须明确；默认不给 Cookie/凭据导出权限。降级先显示超限环境/席位/空间，拒绝自动删除。到期后已运行窗口可安全关闭，宽限和可读/可导出范围按正式政策显示。

## 6. 工程映射与接入顺序

| 现有实现 | 接入位置 | 首次改造边界 |
| --- | --- | --- |
| `profile-repository.js` | 创建模板与快照摘要 | 继续校验 revision、可靠保存，不热更新已有环境 |
| `environment-repository.js` | 环境列表、详情、恢复 | 保留 UUID/目录/快照；新增业务元数据须兼容旧格式 |
| `browser-tabs.js` | 环境窗口内网页标签 | 先解决 Session 归属；旧独立标签环境不合并 |
| `main.js` / `preload.js` | 可信读写/运行命令 | 延续来源校验、隔离、中文错误；不暴露给外部网页 |
| `renderer/index.html` / `app.js` | 主导航、表格、向导 | 分步骤替换界面，避免一次性重写现有业务逻辑 |
| `renderer/browser.*` | 浏览器窗口 | 环境摘要、网页标签、地址、下载与站点权限 |
| `runtime-compat.js` | 设置/启动前检查 | 报告真实版本和实际能力，不能仅看 Schema 字段 |

先把 P0 环境表格、创建与恢复接入本地真实数据，随后代理与浏览器兼容，再做 SaaS 组织与授权。团队/账单入口在未可用时显示明确的规划状态或隐藏，不能把演示数据带入正式产品。

此次高保真原型为独立交付，没有替换现有管理页、安装新项目依赖或修改 Electron/Chromium 代码。

## 7. 验证与开发验收

本次检查可点击原型的创建成功路径、未检查代理阻止继续、筛选无结果、代理错误抽屉、邀请演示和窄屏布局。截图来自浏览器渲染，具体结果见 `原型验收记录.md`；尚未开展真实用户测试和真实多平台运行时测试。

落地时需额外验收：所有状态真实接口映射、输入与批量权限、键盘可访问、中文排版、Windows 缩放、Mac Retina、不同长度业务名、1000 条环境分页、失联和故障恢复。对原型的验收不能代替内核、代理、云安全与支付系统验收。
