# 统一工作台高保真改进计划

## 目标

以高保真稿 [17-统一工作台标签高保真-v2.png](screens/17-统一工作台标签高保真-v2.png) 为验收基准，把指纹浏览器收敛为一个统一窗口：启动后默认显示 SaaS 工作台，工作台是第一个固定标签；创建的每个浏览器环境在同一窗口中显示一个网页标签。

本计划只修改 `fingerprint-browser` 的应用层和界面层，不修改 Electron/Chromium 上游通用能力。指纹、代理、环境目录和会话隔离继续由现有应用层能力提供。

## 高保真稿对应的界面结构

1. **统一窗口**
   - 顶部第一行是浏览器式标签栏，左侧固定“首页”标签。
   - 第二行是后退、前进、刷新和地址栏；没有 Electron 默认菜单。
   - SaaS 首页显示工作空间侧栏、环境统计、筛选区和环境卡片。
   - 选中环境标签后，网页视图占据第二行以下的完整区域，SaaS 页面暂时隐藏；点击“首页”返回工作台。

2. **标签规则**
   - “首页”永远存在、永远位于第一位、没有关闭按钮。
   - 一个环境最多一个标签；已运行环境再次打开时只切换到现有标签。
   - 环境标签显示环境名称，标题过长时省略；所有标签使用弹性宽度，禁止横向滚动条。
   - 关闭环境标签等价于关闭该环境，写入环境状态并刷新 SaaS 列表。

3. **工作台规则**
   - 环境列表中的“打开/进入”按钮必须定位对应环境标签。
   - “运行中”只由真实标签状态驱动，网页或窗口关闭后立即显示“已关闭”。
   - 标签栏不显示环境选择下拉、新建网页标签、新建环境按钮；创建入口只保留在 SaaS 页面。

## 交互与状态验收

| 场景 | 预期行为 | 验收方式 |
| --- | --- | --- |
| 启动应用 | 只创建一个窗口，首页标签选中，默认菜单隐藏 | 原生测试检查窗口数、菜单对象和首页标签 |
| 创建环境 | 在同一窗口新增一个环境标签并切换到该标签 | 检查 `BrowserWindow` 数量和标签快照 |
| 列表点击运行中环境 | 直接选中对应环境标签，不创建新标签 | 检查 `activeId` 与环境 ID |
| 重复打开同一环境 | 保持一个标签并切换，不重复创建 Session | 调用 `newPageTab` 后检查环境标签数量为 1 |
| 多标签 | 标签宽度自动收缩，标签栏 `overflow` 为 `hidden` | DOM 样式检查和窗口缩放检查 |
| 关闭环境标签 | 环境状态变为 `closed`，首页可重新选中 | 检查 `environments:list` 和首页状态 |
| 导航 | 地址栏、后退、前进、刷新只操作当前环境 | 原生网页视图导航回归 |
| 退出应用 | 保存 Cookie、最近网址和环境状态 | 重启恢复测试 |
