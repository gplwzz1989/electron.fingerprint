# Electron 指纹功能批次更新说明

## 1. 更新范围

本批次基于 Electron `37.2.6`、Chromium `138.0.7204.185`，完成了
`FP-01` 至 `FP-18` 共 18 个指纹功能点，以及对应的 Profile 配置链路、Session
隔离、补丁登记和定向测试。

Chromium 侧修改全部通过 Electron Patch System 维护，补丁位于
`patches/chromium/`，并在 `fp-kernel/docs/PATCH_REGISTRY.md` 登记；没有把完整的
Chromium 工作树作为业务代码提交。

本批次构建产物使用 `out/Testing` 配置。该配置不是 Debug 构建，也不是正式发布构建，
而是保留检查项和部分符号信息的测试构建，适合功能验证和回归测试。

## 2. 功能更新

| 编号 | 功能 | 运行时覆盖范围 | 开关或配置 |
| --- | --- | --- | --- |
| FP-01 | 硬件线程数 | `navigator.hardwareConcurrency`，页面与普通 Worker | `hardware.hardwareConcurrency`、`modules.navigator` |
| FP-02 | 设备内存 | `navigator.deviceMemory` | `hardware.deviceMemory`、`modules.navigator` |
| FP-03 | User-Agent | 页面 `navigator.userAgent` 与请求 User-Agent | `browser.userAgent`、`modules.ua` |
| FP-04 | Client Hints | `navigator.userAgentData`、高熵版本和协商后的 `Sec-CH-UA*` | `browser.chromiumMajor`、`modules.clientHints` |
| FP-05 | Locale 与时区 | `navigator.language`、`navigator.languages`、`Accept-Language`、Intl 时区 | `locale.*`、`browser.acceptLanguage`、`modules.locale`、`modules.timezone` |
| FP-06 | Navigator 平台 | `navigator.platform` | `hardware.platform`、`modules.navigator` |
| FP-07 | 屏幕与 DPR | `screen.*`、`devicePixelRatio` | `screen.*`、`modules.screen` |
| FP-08 | WebGL GPU 信息 | `WEBGL_debug_renderer_info` 的 vendor 和 renderer | `graphics.*`、`modules.webgl` |
| FP-09 | Canvas 像素 | 2D Canvas 的 `getImageData()`、`toDataURL()` | `noise.canvas`、`noise.seed`、`modules.canvas` |
| FP-10 | Canvas 文本测量 | `CanvasRenderingContext2D.measureText()` 指标 | `noise.canvas`、`noise.seed`、`modules.canvas` |
| FP-11 | Audio | `OfflineAudioContext` 采样率和离线渲染结果 | `noise.audio`、`noise.seed`、`modules.audio` |
| FP-12 | 字体 | 按目标平台替代或隐藏代表性字体 | `hardware.platform`、`modules.fonts` |
| FP-13 | ClientRects | Element 和 Range 的四类 DOM Rect 查询 | `noise.rects`、`noise.seed` |
| FP-14 | WebGL 像素 | `RGBA + UNSIGNED_BYTE` 的 `readPixels()` | `noise.seed`、`modules.webgl` |
| FP-15 | `navigator.webdriver` | AutomationControlled 场景下不再强制返回 `true` | 无新增 Profile 字段 |
| FP-16 | Headless 与 Runtime Agent | 隐藏 `HeadlessChrome` 产品名，降低 Runtime Agent 特征暴露 | 无新增 Profile 字段 |
| FP-17 | Worker 一致性 | 页面、普通 Worker、ServiceWorker 的指纹值和请求头保持一致 | 复用所属 Session Profile |
| FP-18 | WebRTC 网络地址 | 启用时使用 `disable_non_proxied_udp`，过滤非代理 UDP 主机候选 | `modules.webrtc` |

### 2.1 默认行为和隔离规则

- 未设置 Profile、Profile 的 `enabled` 为 `false`，或对应模块关闭时，继续使用 Chromium
  原生行为。
- Profile 归属于 Session 对应的 BrowserContext，不归属于单个 BrowserWindow。
- 不同 Session 可以使用不同 Profile；Profile A、Profile B 和无 Profile 的 Session
  不互相污染。
- Canvas、Audio、ClientRects 和 WebGL 像素扰动使用 Profile 的 `noise.seed`，同一
  Session 内保持稳定，不同 Session 使用不同 seed 时产生不同结果。
- 当前实现不是完整系统字体枚举伪装；字体功能覆盖的是代表性目标平台字体。
- WebGL GPU 信息覆盖 `WEBGL_debug_renderer_info` 的 vendor/renderer，不修改普通
  `GL_VENDOR` 和 `GL_RENDERER` 查询。
- WebGL 像素扰动当前只处理 `RGBA + UNSIGNED_BYTE`，其他读回格式保留原生结果。

## 3. Session 接口更新

### 3.1 设置 Profile

```js
const { session } = require('electron')

const ses = session.fromPartition('persist:fingerprint-demo')

ses.setFingerprintConfig({
  schemaVersion: 1,
  id: 'win11-cn-desktop',
  enabled: true,
  browser: {
    family: 'Chrome',
    chromiumMajor: 138,
    userAgent: null,
    acceptLanguage: 'zh-CN,zh;q=0.9'
  },
  locale: {
    language: 'zh-CN',
    languages: ['zh-CN', 'zh'],
    timezone: 'Asia/Shanghai'
  },
  hardware: {
    hardwareConcurrency: 8,
    deviceMemory: 8,
    platform: 'Win32'
  },
  screen: {
    width: 1440,
    height: 900,
    availWidth: 1440,
    availHeight: 860,
    deviceScaleFactor: 1.25
  },
  graphics: {
    webglVendor: 'Google Inc. (Intel)',
    webglRenderer: 'ANGLE (Intel, Intel(R) UHD Graphics, D3D11)'
  },
  noise: {
    seed: 'win11-cn-desktop-stable',
    canvas: true,
    audio: true,
    rects: true
  },
  modules: {
    ua: true,
    clientHints: true,
    locale: true,
    timezone: true,
    navigator: true,
    screen: true,
    webgl: true,
    canvas: true,
    audio: true,
    fonts: true,
    webrtc: true
  }
})
```

Profile 的完整字段、类型和必填项以
[`fingerprint-profile.schema.json`](../schema/fingerprint-profile.schema.json) 为准。
当前协议固定 `schemaVersion = 1`、`browser.family = "Chrome"` 和
`browser.chromiumMajor = 138`。

### 3.2 查询和清除 Profile

```js
const current = ses.getFingerprintConfig()
ses.clearFingerprintConfig()
```

- `getFingerprintConfig()` 返回当前 Session 保存的配置对象；没有配置时返回 `null`。
- `clearFingerprintConfig()` 清除尚未锁定的 Session Profile，之后使用 Chromium 原生行为。
- `getFingerprintConfig()` 返回配置本身，不是网页实际探测结果。

### 3.3 生命周期限制

- 必须在该 Session 创建首个 Renderer 或首次导航前调用 `setFingerprintConfig()`。
- 首个 Renderer 创建后再次调用 `setFingerprintConfig()` 会抛出异常。
- Renderer 创建后清除配置不会热更新已经启动的 Renderer；当前不支持运行时热切换。
- 配置通过 Browser Process 校验后序列化为 `--fingerprint-config`，传递给 Renderer
  及其相关 Worker 上下文。

### 3.4 校验与失败回退

接口会拒绝不支持的 Profile 字段、非法平台、非法语言、超出范围的硬件值、无效屏幕
尺寸和不支持的浏览器版本。配置未通过校验时不会部分应用，调用方应修正配置后重新
创建 Session。

通过校验不代表所有网页探针都一定覆盖：每个指纹点仍受对应 `modules.*` 或 `noise.*`
开关控制，并在不适用时回退到 Chromium 原生值。

## 4. 验证情况

### 4.1 已完成验证

- Electron API 指纹专项回归：`15/15` 通过。
- BrowserLeaks 的 JavaScript、Canvas、WebGL、Fonts、WebRTC 页面已由新编译的
  Electron 成功加载并完成定向探针。
- 已验证 User-Agent、请求 User-Agent、`Accept-Language`、Client Hints、平台、语言、
  时区、硬件线程数、设备内存、屏幕尺寸、可用区、DPR 和 WebGL vendor/renderer。
- 已验证 Canvas 像素、Canvas 文本测量、OfflineAudio、ClientRects 和 WebGL 像素的
  Session seed 隔离。
- 已验证页面与普通 Worker 的 User-Agent、平台和语言一致。
- 已验证 `navigator.webdriver = false` 的普通页面行为。
- 已验证启用 WebRTC 策略后候选结果不包含非代理 UDP 主机候选，定向测试中的候选数为 0。
- Electron 增量构建已完成，产物为 `out/Testing/electron.exe`。

### 4.2 验证边界

- FP-16 的 V8 Runtime Inspector 暴露属于 DevTools 协议层行为，仍需独立 CDP/自动化
  兼容性回归；该补丁可能影响依赖 Runtime Agent 的调试工具。
- FP-17 已有页面、普通 Worker、ServiceWorker 和请求链路测试覆盖，但仍建议补充
  ServiceWorker 重启、Renderer 重启和持久 Session 场景。
- 当前主要证据来自定向 API 回归、运行时探针和真实指纹网站，不等同于所有第三方
  反检测网站的兼容性保证。
