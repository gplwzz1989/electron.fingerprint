# SaaS 项目规则

继承仓库根目录 AGENTS.md；以下规则适用于本项目全部界面代码。

## UI 组件统一规范（强制）

- SaaS 的 UI 层统一使用 **shadcn/ui** 作为组件体系，包括页面布局、按钮、表单、选择器、列表、菜单、弹窗、确认框及状态提示。
- 必须使用项目实际集成的组件和适配层，不能仅仿写 CSS、添加同名类或相似外观就声称使用了 shadcn/ui。
- 普通弹窗使用 Dialog；删除等确认使用 Alert Dialog；环境选择使用 Dialog 配合列表或 Command/Select；顶部状态提示使用项目封装的 shadcn/ui 提示组件。成功为绿色，失败为红色。
- 业务界面禁止调用浏览器或系统原生 `alert()`、`confirm()`、`prompt()`；禁止原生方框提示、重复弹框和另建平行组件体系。
- 优先复用项目组件；缺少时先补充公共组件，再接入业务页面。组件只处理交互与展示，权限、业务校验和持久化仍由服务端负责。
- 工作区和系统管理的全部页面统一通过公共适配层使用真实 shadcn/ui 组件；新增页面和交互必须接入此适配层，不得旁路生成未转换的原生控件。不得因组件迁移而改变业务 API、权限校验或持久化流程。
- 保留键盘操作、焦点约束与返回、ARIA 语义及窄屏适配；遵守根目录的静态导航、DPI 和导航层级保护规则。
- 所有用户文案、空状态、错误提示均使用简体中文，不使用演示数据代替真实业务。
- 组件所需依赖必须锁定版本；界面构建产物随网页资源打包，不向 SaaS 服务端运行代码引入界面运行依赖，不在生产页面依赖外部 CDN。

## 授权交互

- 选择平台后只展示精简的环境列表；选定环境立即关闭全部业务弹框，授权继续在客户端进行。
- 授权结果统一以页面顶部气泡提示呈现：成功绿色、失败红色；失败不能被关闭弹框吞掉，必要时提供精简重试入口。
- 页面与客户端授权、打开和状态读取使用纯 JSAPI；能力包检查、下载与本地缓存由客户端负责，网页不参与更新。

## 服务端架构

- HTTP 服务由 NestJS 管理；新增接口按业务域接入模块和控制器，业务校验与数据事务放在服务提供者中。
- 禁止新增独立 `http.createServer()`、旁路 Express 路由或绕过 Nest 生命周期的网络入口。保持现有公开路由、状态码、中文错误响应、CSRF 和 Cookie 行为兼容。
- HTTP 请求正文由业务服务按现有 JSON、表单及支付回调格式读取；调整 Nest 中间件时必须保留原始回调正文、CSRF 与错误响应行为。
- 数据库、邮件、支付、客户端更新和平台发布服务由 Nest 模块提供依赖；关闭应用时释放 Nest HTTP 服务、数据库和后台定时资源。
- MySQL 表间关联、归属校验和删除时的关联清理由业务服务显式执行；禁止在 DDL 中定义 `FOREIGN KEY`、`REFERENCES` 或 `ON DELETE CASCADE`，现存 SaaS 外键由启动迁移移除；需要按关联字段查询时显式建立普通索引。
